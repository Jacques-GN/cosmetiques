
# BÉLORA — Cahier des charges

## 1. Présentation du projet

BÉLORA est une marque fictive de produits cosmétiques. Le projet consiste à créer un site web vitrine élégant permettant de présenter la marque, ses produits et ses valeurs.

Il s'agit d'un projet scolaire individuel réalisé en HTML, CSS, JavaScript et PHP.

## 2. Objectifs

- Présenter l'identité de la marque BÉLORA.
- Mettre en valeur les produits cosmétiques.
- Permettre aux visiteurs de consulter le catalogue et les détails des produits.
- Faciliter la prise de contact.
- Appliquer les notions étudiées en cours.
- Produire un code compréhensible et facile à maintenir.

## 3. Public cible

Personnes intéressées par les soins cosmétiques, la beauté et les produits de soin.

## 4. Pages du site

- index.php : accueil.
- catalogue.php : catalogue des produits.
- produit.php : détails d'un produit.
- apropos.php : présentation de la marque.
- contact.php : formulaire de contact.

Les composants communs seront placés dans includes/header.php et includes/footer.php.

## 5. Fonctionnalités

- Navigation entre les pages.
- Présentation des produits avec images, noms, descriptions et prix indicatifs.
- Affichage détaillé d'un produit.
- Formulaire de contact avec validation.
- Menu adapté aux appareils mobiles.
- Interface responsive sur ordinateur, tablette et téléphone.

## 6. Technologies

- HTML5 : structure des pages.
- CSS3 : design et responsive.
- JavaScript : interactions côté navigateur.
- PHP : inclusion des composants communs et traitement du formulaire.
- MySQL : facultatif, en attente de confirmation du professeur.

## 7. Limites du projet

Le site est une vitrine, pas une boutique en ligne.

La version initiale ne prévoit ni panier, ni paiement, ni espace client.

PHP doit rester limité aux besoins pédagogiques. Le code doit être suffisamment simple pour que l'étudiant puisse l'expliquer au professeur.

## 8. Contraintes

- Travail individuel.
- Niveau technique débutant.
- Délai estimé : 2 à 4 semaines.
- Développement local avec XAMPP.
- Organisation claire des fichiers.
- Aucun mot de passe ni jeton d'accès dans le dépôt.

## 9. Critères de réussite

- Toutes les pages sont accessibles.
- Les liens fonctionnent.
- Le design est cohérent avec l'identité BÉLORA.
- Le site s'adapte aux petits et grands écrans.
- Le formulaire est contrôlé côté serveur.
- Les erreurs importantes sont corrigées.
- L'étudiant peut expliquer les principales parties du code.

## 10. Livrables

- Code source du site.
- Site fonctionnel.
- Documentation technique.
- Tests de fonctionnement.
- Présentation orale du projet.
